About QuickNotes

QuickNotes is a simple note-taking app for jotting down ideas, tasks and reminders. It helps you capture a thought quickly and find it again whenever you need it.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and write your note in the text area.
  3. Save the note so it appears in your notes list.
  4. Click any saved note to read, edit or delete it.

Features

  • Create notes in seconds
  • Edit and delete notes at any time
  • Search through all your notes
  • Works in any modern browser

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
